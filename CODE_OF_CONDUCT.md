# Code of conduct

Treat participants respectfully. Discuss code and evidence without personal
attacks. Harassment, discrimination, threats, doxxing, and publication of private
information are not acceptable in issues, pull requests, or project discussions.
Respect contributors' time, acknowledge their work, and keep feedback relevant
and constructive.

For sensitive concerns, use a private contact explicitly listed by the maintainer
on their GitHub profile. If none is available, request a private contact without
posting personal details or allegations. Security vulnerabilities have a separate
reporting procedure in [SECURITY.md](SECURITY.md).

The maintainer may edit or remove inappropriate content, close discussions, or
restrict participation. Where appropriate, the maintainer will explain the action
without disclosing private information. Apply the same expectations to all
participants, including maintainers.
